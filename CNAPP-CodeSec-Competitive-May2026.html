The bottom line — five things to know in five minutes

If you walk into a CNAPP or CodeSec deal today, here is the field as it actually stands.

CNAPP

  1. Consolidation is the story. Google · Wiz ($32B), Cisco · Splunk, Palo Alto's Cortex Cloud rebrand, Fortinet · Lacework, Tenable · Ermetic. Standalone CNAPPs below $50M ARR are getting rare.
  2. Microsoft still leads on share (~24.7%, Frost) by virtue of Azure, but trails on multi-cloud parity.
  3. Forrester Wave Q1-2026 named only three Leaders — Wiz, Sysdig, Qualys.
  4. Runtime + AI is the new battleground. Sysdig's 5s detection, CrowdStrike's CDR convergence, Wiz's sensor add-on.
  5. CIEM and DSPM are now table stakes, absorbed into the CNAPP SKU.

Code Security

  1. Snyk leads the developer lane ($326M ARR, +7% YoY) but growth has decelerated.
  2. GHAS + GitLab Ultimate own platform-native AppSec. GHAS for Azure DevOps GA since 2024.
  3. Microsoft's Azure DevOps story is GHAS-first. The MSDO extension still ships SDL analyzers.
  4. Wiz Code and FortiCNAPP CodeSec are the CNAPP-converged options competing on cloud-runtime context.
  5. Checkmarx ($150M+ ARR) and Veracode (11× MQ Leader) still default in regulated industries.
FortiCNAPP wins where the customer values fabric breadth over best-in-class point depth. Lead with the Fabric — never with a feature checklist. SE field note · May 2026

Where the value comes from

  • SOC labour collapse. Tier-1 alert investigations drop 70–85%; SOC FTE redeployed to threat hunting.
  • Tooling consolidation. CSPM, CWPP, CIEM, DSPM, KSPM, and CodeSec in one platform typically retires 3–5 point tools — $300K–$1.5M annual licence savings.
  • Cloud-breach exposure reduction. Composite-alert engines reduce dwell time by an order of magnitude versus rule-based CSPM.
  • Audit acceleration. Continuous compliance for PCI-DSS 4.0, NIS2, DORA, FedRAMP — measured in audit hours saved.

Where the FortiCNAPP case is sharpest

  • Fortinet-installed estates. Customers already on FortiGate VM, FortiWeb, or FortiSOAR collapse a 3–4 SKU stack into one Fabric — typical procurement saving 20–35% versus Wiz + standalone SOAR + WAF.
  • Mid-market and APAC channel deals where Wiz / CrowdStrike pricing models price out, and Defender doesn't cover AWS/GCP at parity.
  • Regulated, hybrid estates — FortiAnalyzer correlates cloud + on-prem + branch telemetry in one console.
  • Predictable pricing — resource-based subscription vs Prisma's opaque credit model is the #1 finance objection FortiCNAPP wins on.

Battle cards — six conversations you will actually have

The six matchups Fortinet PreSales SEs encounter weekly, each with the win / lose / Fabric angle and one objection-and-response. Full 21-vendor set available on request.

FortiCNAPP vs Wiz

CNAPP · Forrester Leader · post-Google · $1B+ ARR
The brand-name fight. Concede the UX; win on Fabric and runtime depth.
FortiCNAPP wins
  • Polygraph composite alerts vs Wiz graph queries
  • Native FortiSOAR + FortiGuard + FortiGate east-west
  • Channel-led commercial flexibility (mid-market, APAC)
Where we're challenged
  • Wiz UX and time-to-value are still benchmark
  • Post-Google, Wiz inherits Mandiant intel
  • CISO mindshare heavily Wiz-skewed
Fabric angle
  • One vendor across firewall, WAF, SOAR, CNAPP — collapses 3–4 procurements into one
  • FortiAnalyzer correlates cloud + on-prem + branch

Objection: "Wiz deploys faster."

Response: Concede time-to-first-alert; pivot to day-30 alert quality. Run a 30-day Polygraph vs graph-query benchmark on the same cloud account — the noise reduction wins.

FortiCNAPP vs Microsoft Defender for Cloud

CNAPP · ~24.7% share · Forrester Contender
The hyperscaler-bundle fight. Concede Azure depth; win on multi-cloud and predictable pricing.
FortiCNAPP wins
  • True AWS/GCP parity (Defender is ~60% depth on non-Azure)
  • Vendor-neutral fabric vs hyperscaler lock-in
  • Predictable pricing vs per-plan consumption
Where we're challenged
  • Defender + Entra + Sentinel are tight for Azure-first shops
  • Bundled into Azure invoice — zero finance friction
  • Microsoft partner ecosystem is enormous
Fabric angle
  • FortiAnalyzer ingests Defender + FortiCNAPP signals — co-exist, don't replace
  • SD-WAN, ZTNA, NGFW already in fabric

Objection: "We already pay for Defender."

Response: Pull their last 30 days of Defender findings; benchmark in the same window with FortiCNAPP on AWS/GCP. Practitioners typically see 30–50% additional findings on non-Azure clouds.

FortiCNAPP vs Palo Alto Prisma / Cortex Cloud

CNAPP · Forrester Strong Performer · Cortex migration underway
The platform-vs-fabric fight. Concede breadth; win on pricing and consolidation discipline.
FortiCNAPP wins
  • Predictable resource pricing vs credit model
  • One console vs multiple Prisma UIs mid-migration
  • Lower false-positive rate (Polygraph behavioural)
Where we're challenged
  • Prisma has the broadest module set (DSPM, AI-SPM, CDR all GA)
  • Gartner support score 4.6/5
  • PANW channel and brand are formidable
Fabric angle
  • Cortex Cloud requires PANW Strata + XSIAM — bigger lift
  • Existing FortiGate / FortiWeb customers get the better discount

Objection: "Prisma covers more modules."

Response: 80% of Prisma customers don't activate 60%+ of the SKUs. Map only what they actually use, then compare FortiCNAPP + Fabric — usually fewer SKUs cover the same surface for less.

FortiCNAPP vs CrowdStrike Falcon Cloud Security

CNAPP · Forrester Strong Performer · $800M+ ARR
The endpoint-vendor expansion fight. Concede agent ubiquity; win on TCO and AppSec breadth.
FortiCNAPP wins
  • Lower TCO; CrowdStrike is enterprise-priced
  • FortiCNAPP CodeSec included; CrowdStrike has no AppSec
  • Better CSPM / DSPM breadth standalone
Where we're challenged
  • Falcon endpoint ubiquity = "one agent" story
  • Threat-intel brand unmatched
  • Falcon CDR is mature

  • FortiClient + FortiEDR + FortiGate + FortiCNAPP = full Fabric

Objection: "We have Falcon everywhere already."

Response: Falcon Cloud Security is a paid add-on, not free. Run modules comparison; pricing and AWS/GCP CSPM depth typically favour FortiCNAPP.

FortiCNAPP CodeSec vs Snyk

Code Security · $326M ARR · developer favourite

What's hot in CNAPP now — the six things every roadmap is racing toward

Themes drawn from Forrester Wave Q1-2026, vendor roadmaps at RSAC / Black Hat 2026, and the customer conversations Fortinet SEs report most often.

Hot · #1

Agentic AI security agents

Wiz, Orca, CrowdStrike, Palo Alto, and Defender have all shipped "agentic" SecOps and remediation agents in preview. Expect every CNAPP roadmap to claim one by year-end.

FortiCNAPP angle: SmartFix + FortiSOAR playbooks already deliver the remediation outcome — agentic AI is a packaging story.
Hot · #2

AI-SPM as a CNAPP module

AI workloads, LLM endpoints, prompts, and training data are now first-class assets. Cortex Cloud 2.0 added AgentiX; Wiz added an AI-SPM SKU; Defender added AI workload posture.

FortiCNAPP angle: Polygraph baselines extend naturally to GenAI service identities and API calls — published roadmap.
Hot · #3

Code-to-cloud-to-SOC convergence

Prisma + Cortex (PANW), Defender + Sentinel, FortiCNAPP + FortiAnalyzer / FortiSOAR. CNAPP is no longer a posture tool — it is a SOC feed.

FortiCNAPP angle: Security Fabric is the most mature single-vendor expression of this convergence today.
Hot · #4

Runtime sensors return

Pure-agentless is no longer enough. Wiz Sensor, Orca Runtime, Defender for Containers all add optional lightweight sensors. Sysdig and CrowdStrike were here first.

FortiCNAPP angle: Optional Lacework agent + agentless snapshots — choose per workload, not per vendor.
Hot · #5

Identity-first CNAPP

Tenable / Ermetic set the bar; Wiz, Defender + Entra, and FortiCNAPP have closed it. Toxic-combination and JIT entitlement are now table stakes.

FortiCNAPP angle: FortiAuthenticator + FortiGate ZTNA + FortiCNAPP CIEM = identity-aware enforcement no pure CNAPP can match.
Hot · #6

Compliance-as-product

European regulation (DORA, NIS2, EU AI Act) has overtaken NIST as the buy-driver for CNAPP in EMEA. Every vendor now ships out-of-the-box control mappings.

FortiCNAPP angle: Compliance packs ship with FortiAnalyzer report templates — single audit pane across cloud + network.

The future of CNAPP — six predictions for 2026–2028

By 2028, "CNAPP" disappears as a category. What is sold today as CNAPP is becoming the operating system of cloud security. Six predictions Fortinet PreSales should be ready to defend.

01

CNAPP collapses into the SOC platform

The code-to-cloud-to-SOC convergence (Prisma + Cortex, Defender + Sentinel, FortiCNAPP + FortiAnalyzer) finishes by 2027. Standalone CNAPP becomes a feature inside the broader SecOps platform.

Implication

Sell the FortiCNAPP + FortiSOAR + FortiAnalyzer bundle, not the CNAPP SKU alone.

02

AI workloads become the new attack surface

LLM endpoints, vector stores, model weights, prompt logs, and agent workflows are the new crown jewels. AI-SPM moves from a checkbox to a CNAPP module sold separately.

Implication

FortiCNAPP must extend Polygraph to AI service identities, prompt-injection telemetry, and model-weight integrity checks — already roadmap.

03

Agentic remediation replaces ticket-driven SecOps

Today: alert → ticket → engineer fixes. By 2027: agent triages, scopes blast radius, proposes patch, opens PR, monitors rollout, closes loop.

Implication

FortiSOAR + FortiCNAPP SmartFix is the agentic-remediation play today — package and price for outcome.

04

Pure-agentless ends; sensor + snapshot becomes the norm

Wiz, Orca, and Defender have all added sensors. By 2027 the architectural debate is hybrid by default — choose the data-collection mode per workload.

Implication

FortiCNAPP's Lacework agent + agentless model is already there; lead with architectural choice, not deployment friction.

05

Hyperscaler bundle wins multi-cloud — slowly

Microsoft inside Azure, Wiz inside Google. AWS will buy or build. The independent CNAPP vendor relies on partner-led GTM, fabric breadth, or vertical depth. There is no fourth lane.

Implication

Fortinet's independence + Security Fabric is the credible alternative for buyers wary of hyperscaler lock-in.

06

Compliance becomes the budget-unlock

DORA (Jan 2025 enforcement), NIS2, EU AI Act, evolving SEC cyber-disclosure rules. CISOs increasingly justify CNAPP spend via audit cost-avoidance, not breach prevention.

Implication

Sell FortiCNAPP's compliance pack and FortiAnalyzer reporting as the audit-acceleration story; quantify auditor-hours saved.
