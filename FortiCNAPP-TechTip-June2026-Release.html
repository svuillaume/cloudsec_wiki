Feature 1 of 2 GA Platform UX · Alerts
Alert Dashboard: View Alerts by Severity, Category, or Sub-Category

The Alert summary bar chart has been updated with a new grouping toggle, giving analysts three distinct ways to analyse alert activity at a glance — without leaving the Alert view or switching tools.

Where this appears

  • Alerts page (main alert dashboard)
  • Threat Alerts tab in AWS CloudTrail
  • Threat Alerts tab in Azure Activity Log
  • Threat Alerts tab in GCP Audit Log

Available groupings

GroupingValuesWhen to use
Severity Critical · High · Medium · Low · Info Default view — understand the risk distribution across your alert backlog at a glance
Category Anomaly · Policy · Composite Distinguish Polygraph behavioural detections (Anomaly) from policy violation alerts (Policy) and correlated multi-signal findings (Composite)
Sub-Category Application · Cloud Activity · File · Machine · User · Platform · Kubernetes Activity · Registry · SystemCall · Host Vulnerability · Container Vulnerability · Threat Intel Drill into specific signal types — e.g. identify a spike in Cloud Activity alerts during an incident investigation, or isolate Kubernetes Activity alerts post-deployment

Behaviour

  • Select a grouping and the chart and legend update immediately — no page reload required
  • The toggle is automatically disabled when no alerts are present in the selected time range, preventing confusion from an empty chart state
Scope limitations: The Compliance sub-category is not shown on Threat Alerts views (AWS CloudTrail, Azure Activity Log, GCP Audit Log) — compliance findings are scoped to the main Alerts page only. Risk Alerts is not affected by this change and continues to display the severity-only view.
PreSales / CISO value: The Category grouping (Anomaly / Policy / Composite) is particularly useful in executive briefings — it immediately communicates whether your alert mix is dominated by behavioural ML detections vs. policy rule violations vs. correlated high-confidence findings. A high Composite count with low Policy noise is the ideal signal maturity posture to highlight.

Feature 2 of 2 GA Threat Intelligence · Security Fabric
FortiGuard IoC Feed Integration

FortiGuard is now integrated as a threat intelligence source in FortiCNAPP. FortiGuard indicators of compromise (IoCs) — malicious IPs, domains, and file hashes maintained by Fortinet's FortiGuard Labs threat research team — are ingested into the FortiCNAPP threat intelligence database and used to enrich detections across the platform in real time.

This is the first direct FortiGuard Labs intelligence feed flowing into FortiCNAPP, marking a significant deepening of the Security Fabric integration. All FortiCNAPP detection engines that perform IoC matching now benefit from FortiGuard's extensive, continuously updated threat intelligence — the same intelligence that powers detection across the entire Fortinet Security Fabric.

Security Fabric Integration

FortiGuard Labs → FortiCNAPP: How the integration works

  • Ingestion: FortiGuard IoCs (malicious IPs, domains, file hashes) are continuously ingested into the FortiCNAPP threat intelligence database — the same database FortiCNAPP uses for all IoC-based matching
  • Detection enrichment: All FortiCNAPP detection engines that rely on IoC matching now run against the expanded FortiGuard feed — improving identification of known malicious infrastructure in your cloud environment
  • Alert tagging: Alerts include a FortiGuard tag when matched indicators originate from FortiGuard intelligence — enabling analysts to immediately distinguish FortiGuard-sourced detections from other threat intel sources
  • IP address enrichment: IP address detail pages now include a FortiGuard link providing direct access to IoC details in FortiGuard Labs — one click from an alert to full threat context
  • File reputation enrichment: File reputation is enhanced with FortiGuard data; file hash detail pages include a FortiGuard link for additional context on malicious files

Detection coverage expanded by this integration

  • Known C2 infrastructure: CloudTrail and Polygraph detections of outbound connections to FortiGuard-confirmed command-and-control IP ranges and domains
  • Malicious file hashes: Container image and host file integrity monitoring enriched with FortiGuard file reputation data
  • Phishing and malware domains: DNS lookup anomalies matched against FortiGuard domain reputation feeds
  • Known threat actor infrastructure: IP addresses associated with tracked threat actor groups — FortiGuard maintains one of the largest commercial threat actor tracking databases globally
Security Fabric positioning: This integration formally connects FortiCNAPP to the broader FortiGuard intelligence ecosystem — the same feeds that power detection in FortiGate, FortiMail, FortiWeb, and FortiEDR across the Security Fabric. A threat actor IP blocked by a customer's FortiGate NGFW can now trigger a correlated detection in FortiCNAPP if that same actor targets the cloud workload layer. This is the cloud-native expression of Security Fabric cross-product correlation.
PreSales framing: "Datadog detects, Fortinet enforces" — and now Fortinet's threat intelligence enriches the detection itself. No other standalone CNAPP vendor ships with direct integration to a global threat research team of this scale. FortiGuard Labs processes over 100 billion security events daily across the Fortinet installed base; that intelligence now flows into FortiCNAPP detection.
